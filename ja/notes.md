# 補足ノート

本ファイルは、仕様本文 (CIP-0〜15) に含めるとノイズになる補足事項をまとめたものです。
スコープ外事項の明示や、実運用上の挙動の解説など、規範的な効力を持たない情報を扱います。

## スコープ外事項

以下は本仕様群 (CIP-0〜15) の意図的なスコープ外です。

* エンティティの新規登録、およびリモートエンティティの所属受け入れ (admission) の可否判断・
  ワークフロー。これらは完全にサーバー実装・運用の自由とします。
* エラー応答のボディ形式。エラーは HTTP ステータスコードによって表現され、
  ボディの JSON 形式等は実装定義とします。
* blob の**アップロード (取り込み) 手段**。これはストレージモジュール等の別仕様に委ねられます。
  CIP群が定義するのは blob の命名と解決のみです。
  blob の解決要求を受けたサーバーは、実体を保持するストレージエンドポイントまたは
  owner の所属サーバーへの HTTP リダイレクトで応答してもよい (MAY)。
  取得したコンテンツが URI 中の SHA256 ハッシュと一致することは、取得側が検証するべきです (SHOULD)。
